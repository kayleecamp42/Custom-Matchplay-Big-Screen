Community QR placeholder

Your tournament community belongs here!

This QR code is a placeholder. The tournament director should configure it to point to a place where players can connect, such as a Discord server, Facebook group, or another community gathering location.

To change it, open src/config.js in the Custom Matchplay Big Screen project and set communityUrl to your full community link:

communityUrl: "https://discord.gg/your-invite",

Set communityLabel to the name you'd like shown above the QR code. Save the file and refresh the display.

This is a local page served by the app. For phones to scan the placeholder QR, the display must be opened using a network address reachable from those phones rather than localhost.
